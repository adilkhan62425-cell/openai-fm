जंगल में तोता, कबूतर और चूहा तीनों पक्के दोस्त थे।
एक दिन घूमते-घूमते उन्हें एक हिरन जाल में फँसा मिला।

तोता बोला:
“दोस्तों, जल्दी मदद करो!”

कबूतर ऊपर से देखने लगा,
“कोई शिकारी नहीं है!”

चूहे ने अपने तेज़ दाँतों से जाल काट दिया।
हिरन आज़ाद हो गया और बोला,
“धन्यवाद दोस्तों!”

तीनों हँसते हुए बोले,
“यही होती है सच्ची दोस्ती!
